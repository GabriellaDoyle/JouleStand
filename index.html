Quick Start

Install a skill in 3 steps

Every skill works the same way. No IT ticket, no approval queue — just download, upload, and go.

1

Download the skill

Click "Download skill" on any skill card or from the Joule Hub. You get a small file — a .md or .zip.

2

Open Extensions, click Add Skill

In Joule Desktop, hit the Extensions panel (puzzle icon), then + New and Add Skill and Upload.

3

Drag, drop, done

Drop the file in. The skill installs in about one second. Just ask Joule in plain language to use it.
